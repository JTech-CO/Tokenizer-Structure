LLM 토크나이저, 브라우저에서 직접 뜯어보기 🔍

1. LLM은 텍스트를 토큰으로 나눈 뒤 정수 ID로 처리한다. 텍스트 API의 컨텍스트 한도와 입력·출력 과금도 주로 토큰 수를 기준으로 하지만, 검색·도구·이미지·오디오에는 별도 과금이 있을 수 있다.
2. 이 시뮬레이터는 Hugging Face Tokenizers의 네 컴포넌트를 기준으로 보여준다. ① 정규화 ② 사전 토큰화 ③ BPE·WordPiece·Unigram 같은 토큰 모델 ④ 후처리. 모델에 따라 일부 단계가 없거나 규칙이 다르고, 특수 토큰도 항상 추가되는 것은 아니다.
3. GPT-4o·Llama 4·Qwen3.5처럼 byte-level 계열은 UTF-8 바이트에서 시작한다. 원시 조각이 ìķĪ처럼 보여도 바이트를 순서대로 역매핑하고 스트리밍 디코드하면 원문으로 복원된다. 여러 바이트가 하나의 토큰으로 병합될 수도 있어 바이트 수와 토큰 수가 1:1인 것은 아니다.
4. 같은 의미라도 언어·문장·토크나이저에 따라 토큰 수가 달라진다. 어느 언어나 모델이 항상 효율적이라고 일반화할 수 없으므로, 매트릭스 색도 각 샘플 행 안에서만 비교해야 한다.
5. 브라우저에서 검증된 공개 artifact 6개(GPT-4o o200k·Qwen3.5 0.8B·Llama 4 Scout tokenizer·Gemma 3 1B·DeepSeek-V3·BERT multilingual)를 구동해 컴포넌트 시각화·2열 비교·입력 샘플 매트릭스를 제공한다. 비용 화면은 현재 토크나이저 토큰 수에 수록 API 단가를 대입한 근사다.
6. 설치도 회원가입도 없이 링크만 열면 사용할 수 있고, 코드는 공개돼 있다.
